# 📰 React News Aggregator

A modern, responsive news application built with **React**, **Vite**, and **Tailwind CSS**. This application fetches real-time news articles using the **NewsData.io API**, featuring dynamic category routing, search functionality, and robust error handling for missing images.

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![React](https://img.shields.io/badge/React-18.x-61DAFB.svg) ![Vite](https://img.shields.io/badge/Vite-5.x-646CFF.svg)

## 🚀 Features

* **🔥 Live Headlines:** Real-time news updates from the US (configurable for other regions).
* **📂 Category Filtering:** Dedicated sections for Business, Technology, Sports, Health, and more.
* **🔍 Search Functionality:** Real-time search for specific news topics.
* **📱 Responsive Design:** Fully responsive UI styled with Tailwind CSS.
* **🛡️ Robust Image Handling:**
    * Automatically detects broken images (403/404 errors).
    * Replaces missing media with a clean `placehold.co` placeholder.
* **📄 Static Pages:** Includes standard pages like About, Contact, Privacy Policy, and Terms.

## 🛠️ Tech Stack

* **Frontend:** [React.js](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Routing:** [React Router DOM](https://reactrouter.com/)
* **API:** [NewsData.io](https://newsdata.io/)
